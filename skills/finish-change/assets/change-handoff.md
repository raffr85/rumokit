# Change handoff

## Requested result and artifact

State the accepted user outcome and its source, then the exact repositories, revisions, branches, builds, or working state. Distinguish integrated changes from worker-only artifacts.

## Material changes

Summarize behavior and contracts, not a file dump.

## Evidence and review

Compare expected capabilities with delivered behavior and evidence. Record fresh checks, boundaries exercised, review findings, CI state, and what the user still cannot do or rely on.

## Dependencies and release order

List only real version, migration, rollout, or integration edges.

## Blockers and approvals

Name unresolved decisions, failures, credentials, external actions, or required owners.

## Readiness

Choose `READY_FOR_NEXT_STEP`, `NOT_READY`, or `INCONCLUSIVE`, then state the exact next action.
